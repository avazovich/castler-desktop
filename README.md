# Castler — Mac va Windows ilovasi

Castler Studio OS ish maydonining kompyuter ilovasi. Ilova jonli Castler’ni ochadi va keyingi versiyalarga o‘zi yangilanadi.

## Yuklab olish

Eng so‘nggi versiya: **[Releases → Latest](https://github.com/avazovich/castler-desktop/releases/latest)**

**Mac** — `Castler-…-Mac.dmg`
1. Faylni oching va **Castler**’ni **Applications** papkasiga torting.
2. Birinchi ochishda macOS ogohlantiradi: **System Settings → Privacy & Security → Open Anyway**.

**Windows** — `Castler-…-Windows-Setup.exe`
1. Faylni oching. “Windows protected your PC” chiqsa: **More info → Run anyway**.
2. Castler Start menyusida paydo bo‘ladi.

Bir marta o‘rnatilgandan keyin yangi versiyalar avtomatik o‘rnatiladi.
